# Olist Business Analysis
F2026 repository for exam in Data Management and Visualization

## Purpose
This repository serves a codebase and general version control tool for iterations of data exploration, 
analysis and visualization of the provided .csv files relating to Olist.
The aim of the exam is to identify and analyze patterns and ultimately provide 
a report of recommendations and findings based on the data.

## Planned frameworks and methods
In terms of framework and methods, exploratory analysis in R to identify interesting patterns will be done. 
The data will then be visualized in Tableau. 
Based on this recommendations and findings will be communicated.
